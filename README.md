# Senior Frontend Interview Sandbox

A deliberately small Next.js eCommerce application for practicing frontend interview tasks. Start in [`CHALLENGES.md`](./CHALLENGES.md), use [`INTERVIEW-CHEATSHEET.md`](./INTERVIEW-CHEATSHEET.md) when stuck, and see [`RESET.md`](./RESET.md) before repeating a session.

## Commands

```bash
npm run dev
npm run build
npm run lint
npm run test
npm run test:watch
npm run typecheck
```

The fake catalog endpoint is at `/api/products`. Add `?error=true` to receive a simulated `503` response.
